# Capstone: The PetalMart Free-Shipping Decision

Statistics for Data Science · about 10 hours

## Business use case

PetalMart's leadership wants to know whether lowering the free-shipping threshold from ₹999 to ₹699 should go to all customers. A four-week A/B test has run, and earlier a same-day delivery rollout happened in six cities without randomization. Profile and clean the data, check the experiment's validity, estimate effects on conversion, average order value and profit with frequentist and Bayesian methods, cross-check with the observational rollout, and write a decision memo.

## Data source

`petalmart_shipping_test` is **Coral Petal synthetic data**, generated by [`../datasets/generate_petalmart_shipping_test.py`](../datasets/generate_petalmart_shipping_test.py) with seed 2026. No real customer data is used.

```bash
cd statistics-for-data-science
python datasets/generate_petalmart_shipping_test.py --out datasets/data/petalmart_shipping_test --seed 2026
```

The data contains realistic problems to find and fix: duplicates, invalid values and missing fields.

## Tasks

1. Data pull, profile and cleaning log (Modules 01, 02).
2. Validity checks: sample ratio mismatch and covariate balance (Modules 04, 05).
3. Conversion difference with CI and p-value; AOV difference with a bootstrap CI (Modules 05, 10).
4. Bayesian view: probability treatment is better, by customer type (Module 06).
5. Profit model per user and variant (Module 03).
6. Drivers: logistic regression with a variant × customer type interaction (Modules 07, 08).
7. Segment view with multiple-testing correction (Module 05).
8. Observational cross-check: naive comparison versus difference-in-differences on the city rollout (Module 11).
9. Decision memo (1 page) and a 5-slide readout (Module 12).
