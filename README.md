## Get started

**In Google Colab (nothing to install):** open a build notebook from its course README with **Open in Colab**, run the first cell (it clones this repository and generates the data), then choose File → Save a copy in Drive and work in your copy.

**On your own machine** (Python 3.11 or later, and Git):

```bash
git clone https://github.com/CoralPetalAI/CoralPetalAI-Academy.git
cd CoralPetalAI-Academy
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd statistics-for-data-science
python datasets/generate_petalmart_core.py
jupyter lab
```

In JupyterLab, open `builds/build_00_setup.ipynb`, or create a new notebook and run `import pandas as pd; print(pd.__version__)` to check the setup.

Every dataset is **Coral Petal synthetic data**: generated by a script in the course's `datasets/` folder with a fixed seed, so every learner gets the same data. No real customer data is used.
